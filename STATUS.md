## Hand-over: commands in order

Run every command from the project folder. **Stop the server before any build**, because only one process may hold a model.

**1. Models.** Both Gemma repos are already in the Hugging Face cache (they resolve offline). Only if one is missing:

```bash
uv run hf download mlx-community/gemma-4-12B-it-qat-4bit      # 11.0 GB
uv run hf download mlx-community/gemma-4-31B-it-qat-4bit      # 28.8 GB
```

**2. Free memory.** Quit Ollama (or `ollama stop <model>`), games and other large programs. The 31B needs about 29.5 GB; Metal allows about 30.2 GB on this Mac, so it only fits with everything else closed.

**3. Build Gemma 4 12B** (each stage is skipped if done, so re-running resumes; progress and ETA are printed):

```bash
uv run python scripts/build_model.py --model gemma4-12b --stage all
```

or stage by stage, in this order:

```bash
uv run python scripts/build_model.py --model gemma4-12b --stage extract3k   # 3k places, every layer (model)
uv run python scripts/build_model.py --model gemma4-12b --stage sweep       # probe error per layer (CPU)
uv run python scripts/build_model.py --model gemma4-12b --stage full        # 40,485 places, best layer +-3 (model)
uv run python scripts/build_model.py --model gemma4-12b --stage final       # final probe and believed map (CPU); model now "available"
uv run python scripts/build_model.py --model gemma4-12b --stage fictional   # 50 invented names (model)
uv run python scripts/build_model.py --model gemma4-12b --stage political   # political map (CPU)
uv run python scripts/build_model.py --model gemma4-12b --stage gate        # layer-band sweep and gate (model); model now "editable"
uv run python scripts/build_model.py --model gemma4-12b --stage menu        # baseline questions and validated pairs (model)
```

Files go to `models/gemma4-12b/`, `results/models/gemma4-12b/` and `activations/gemma4-12b/`. `--force` redoes a stage.

**4. Build Gemma 4 31B:** the same commands with `--model gemma4-31b`.

**5. Start the server** on any built model (the page can also switch):

```bash
uv run uvicorn terra.server:app --port 8000                        # Qwen (default)
TERRA_MODEL=gemma4-12b uv run uvicorn terra.server:app --port 8000
TERRA_MODEL=gemma4-31b uv run uvicorn terra.server:app --port 8000
```

**6. Automated checks** (the browser and API checks were extended for v2 but not run):

```bash
uv run python -m pytest -q tests                      # code only, no model
uv run python scripts/demo_check.py                   # server stopped first; starts its own Qwen server
uv run python scripts/ui_check.py                     # with the server running
uv run python scripts/ui_check.py --switch gemma4-12b # also switches to Gemma 12B and back (slow)
```

**7. Regenerate the write-ups** after any build (CPU only): `uv run python scripts/summarise_results.py`, `uv run python scripts/write_demo_md.py`, `uv run python scripts/make_figures.py political_map`.

## Things the humans must know

- **Close games, Ollama and other GPU-heavy apps before the demo and before any build.**
- Only one process can hold a model. The lock file is `models/.model_in_memory.lock`; a lock left by a crashed process is ignored automatically.
- Switch models before the judges arrive: loading a Gemma model is not instant, and every request returns "switching models" (503) until it finishes.
- Gemma models have no "move: X stays X" mode and no suggested worlds (those were built for Qwen only); live rewrites still work.
- `.venv`, `activations/` and `models/` are symlinks to `~/terra-local/` (outside OneDrive). Run everything with `uv run python ...` from the project folder.
- Models load offline. `HF_HUB_OFFLINE=1` is now set in `terra/backends/hf.py`; the MLX loader only reads the local cache and prints the download command if a model is missing. Set `TERRA_ALLOW_NETWORK=1` only to download.
- The tier-1 edit swaps identity (Paris "becomes" Sydney: it names the Sydney Opera House). Tier 2 keeps identity, and works often, not always.
- If v2 misbehaves on stage: copy `snapshots/pre_v2/` back over `terra/`, `scripts/` and `web/` to get the 17:20 demo exactly.
