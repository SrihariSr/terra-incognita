## Things the humans must know

- **Close games and other GPU-heavy apps before the demo.** Roblox was running during part of the build and made every model call several times slower.
- Only one process can hold the model (about 15 GB of the 36 GB). Stop the server before running any script in `scripts/` that loads the model.
- `.venv`, `activations/` and `models/` are symlinks to `~/terra-local/` (outside OneDrive). Run everything with `uv run python ...` from the project folder.
- The model loads offline (`HF_HUB_OFFLINE=1` is set inside `terra/model.py`); set `TERRA_ALLOW_NETWORK=1` only if the model ever needs downloading again.
- The tier-1 edit swaps identity (Paris "becomes" Sydney: it names the Sydney Opera House). Say so on stage; tier 2 is the version that keeps identity, and it works often, not always.
- The Finance tab is gone (judges: finance not needed). The Rewrite tab replaces it.
